# KPN shared brand foundation — upgrade candidate 1.2.4

This consolidates existing brand assets; it is not a new identity.

- Display name: Kebbi Progressive Youth Network, matching the existing official logo, current web shell and native Settings screen. Confirm this with the owner before release.
- Short name: KPN.
- Motto: One Voice, One Change.
- Do not redraw/replace the original torch/hands/phone emblem.
- Preserve brand green `#28A745` and blue `#0066CC`.
- Action green: `#176B36`, already used by native Android; white button labels use this darker derivative.
- Light canvas/surface/text: `#F6F8F6` / `#FFFFFF` / `#17251C`.
- Dark canvas/surface/text: `#121A15` / `#19221C` / `#E6EBE7`.
- Appearance: System / Light / Dark; device-local choice. Existing web dark-mode preferences migrate.
- System sans typography, clear headings, readable body text, 4/8/12/16/24/32/48/64 spacing.
- Public home: identity and useful content, not invented statistics or promotional imagery.
- Role workspace header: role, jurisdiction and identity, not rotating motivational text.
- Public Opportunities uses the same explicit name on web and Android.
- Status descriptions and permissions must come from the backend. Do not equate “Telegram verified” with “membership approved.”

The source test checks matching brand/action colours. Full screen-by-screen accessibility and native visual acceptance remain release gates, not claims implied by this document.
